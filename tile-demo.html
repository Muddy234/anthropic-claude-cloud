How This Works

These tiles are defined entirely in JavaScript as arrays of characters, where each character maps to a color in a palette. No external image files needed!

Example:
pixels: ["DMMMD", "DMLLD", "DMMMD"]
palette: { 'D': '#1A1A1A', 'M': '#2A2A2A', 'L': '#3A3A3A' }

The TileRenderer converts these definitions to Canvas drawings, with support for scaling, palette swapping, environment theming, and caching.

Tile Properties:
- walkable: Whether entities can walk on this tile
- type: Category (floor, wall, hazard, door, etc.)
- animated: Whether the tile has animation frames
- hazard: Special effect (slow, slippery, damage)
