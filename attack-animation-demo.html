Attack Animation System

Attack animations use the same pixel-art system as monster sprites. Each attack is defined as a series of frames with pixel data, palettes, and timing.

Frame Structure:
{ duration: 50, pixels: [...], palette: {...}, transforms: {...} }

Attacks support rotation, scaling, alpha blending, and element-based palette swapping. Yellow badges indicate placeholder sprites that need final art.
