How Text-Based Animation Works

Each frame is a 32x32 grid of characters. The character . is transparent, and other characters map to colors via the palette.

Animation is created by manipulating the text:

- Shifting rows: Move pixels up/down for vertical motion
- Shifting columns: Move pixels left/right for horizontal motion
- Diagonal shifts: Combine both for rotation approximation
- Key poses: Use different base sprites (down, left, right) as anchor frames

This demo generates 6 frames by programmatically shifting the base sword sprite to simulate a swing animation. The same technique works for any body part.
