How This Works

All sprites are 32x32 pixels defined in JavaScript as arrays of characters, where each character maps to a color in a palette. No external image files needed!

Location: assets/sprites/*-sprite.js (individual files)

Example:
width: 32, height: 32
pixels: ["..OOO..", ".OEEOO.", "OOOOOOO", ...] (32 rows of 32 chars)
palette: { 'O': '#FF6B35', 'E': '#FFFF00' }

The SpriteRenderer converts these definitions to Canvas drawings, with support for scaling, palette swapping, flipping, and caching.
